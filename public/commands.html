Lista de Comandos

O agente é o caminho principal. O terminal da página Descoberta aceita comandos ADB e do agente na mesma linha.

Agentes (principal)

Ação Descrição Status
info
botão "Pedir info" 		A box responde no próximo heartbeat com modelo, Android, tela, idioma e User-Agent. Não usa ADB: a própria página /agent envia os dados. ✓ Ativo
env
botão "Ambiente" 		Devolve platform, UA-CH, núcleos, memória, WebGL e rede do navegador da box — útil para saber se o aparelho é Android ou um navegador Linux. ✓ Ativo
open <url-http(s)>
botão "Abrir site" 		Abre uma URL no navegador da box. Útil para testes e atalhos. ✓ Ativo
remover agente
botão "Remover" 		Tira a box da lista. Se a página do agente continuar aberta, ela se registra de novo. ✓ Ativo

list 192.168.1.50 		Identifica o aparelho e, se o ADB estiver acessível, exibe um painel completo com:
  • Tipo detectado (Android TV, Apple, roteador) e modelo/fabricante

  • Memória RAM: total, em uso (com barra de progresso), disponível

  • Bateria: nível %, status e temperatura

Mapa de capacidades

Carregando capacidades…
Como os comandos funcionam: os comandos de agente são enfileirados no servidor e entregues à box no heartbeat seguinte (box → PC, sem portas abertas). Os comandos marcados como ADB (apps, install, uninstall, screen, push, reboot) rodam no servidor Node.js local via adb e só funcionam se a box expuser a depuração e autorizar a conexão. O navegador da página /agent não tem permissão para instalar ou remover apps — para isso é necessário ADB. O terminal não é um shell livre — apenas os comandos listados aqui são aceitos. Em aparelhos ligados por cabo USB, use o serial exibido por adb devices como alvo (ex.: apps RQ8R205WKDW). Para o ADB funcionar em Android 11+ é necessário pair com o código exibido na TV; em Android 10 ou menor, basta connect ip:5555 e aceitar o aviso na tela.
